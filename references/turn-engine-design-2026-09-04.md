## 二、回合制引擎规格概要

### 回合 = 意图单元（宁合不切）
```
切分规则：
· 围绕同一意图连说 5 句 → 仍一回合
· 同一个人中途换意图（抱怨→提要求）→ 切两回合
· 打断但未改变对方意图 → 不算新回合
· 拿不准 → 默认不切
意图切换信号：转折词 / 话题词 / 情绪转向（无信号不切）
```

### 沉默规则
```
· 实时：轮到该回应却 5 秒+ 未开口 / 已读不回 → 记"沉默行动"
· 复盘转写：由用户标注"这里沉默了约 X 秒"，AI 不猜秒数
· 铁律：沉默是否成回合，取决于"是否轮到对方回应"——非所有停顿都算
```

### 对方行动（观察编码 · 6 类）
| 类 | 名称 | 处理 |
|---|---|---|
| ① | 话语·内容型 | 记录意图/话题，**不进**贝叶斯 |
| ② | 姿态型 | 动物姿态（Lion/Mouse/Monkey/T-Rex × 好坏）→ **进 P2 更新** |
| ③ | 沉默行动 | 进判读（回避/思考/对抗?） |
| ④ | 岔题/转移 | 本身是证据（回避信号） |
| ⑤ | 情绪爆表 | → 触发 venting 例外（暂停更新） |
| ⑥ | 无行动（回合外） | 背景噪音，不算 |

### 我方行动（决策编码 · 三档 × 五类招式）
```
回合结束 → 看 margin → 定粒度档 → 从菜单选招
① 宽泛档 (margin<0.15)   低承诺回应：维持在场、不押注、顺带收集
                         例："我想多听听你怎么想" / 主动沉默观察
② 中程档 (0.15–0.30)     定向：探针收窄到混淆对 / 验证句确认方向
③ 精确档 (≥0.30)         切 Good 姿态、具体话术、直接给适配

招式：A 话术·适配  B 探针  C 验证句  D 沉默  E 退出/设界
粒度纪律：模糊必须显式声明为宽泛档招式并知道在收集什么——模糊是策略，不是逃避
```

## 三、产品定位（ND 闭源版）

- **使用者**：多样 ND 客户（ASD / ADHD / AuDHD / PDA……），非用户本人
- **输出要求**：ND 友好——字面、结构化、零隐喻负担；P1 内省探针需**引导式版本**（给选项而非开放题，客户可能缺自我觉察起点）
- **核心功能**：NT 行为翻译器——"他那样说不是讨厌你，是 Lion 在定议程"的解离价值
- **闭源分层**（若未来开源，按此拆）：
  - 可开源：L0 理论层（整合逻辑，全是公共知识）
  - 可开源：L1 引擎层（回合制规范、P0-P4 流程、教学版明牌规则）
  - 闭源：L2 战术层（scam-radar 检测清单、探针话术库、证据表条目——安全工具开放悖论）
  - 永不公开：L3 个人经验层（Luci 阳谋条目 = 弱点地图）
